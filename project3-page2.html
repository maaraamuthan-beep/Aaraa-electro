Arduino LED Blink Project - Arduino Code & Build Video

Arduino Code (LED Blink)

Copy this code into the Arduino IDE (No external library required). 
// Arduino LED Blink Project - Aaraa Electro
// Blinks an LED connected to Digital Pin 13 with a current-limiting resistor

const int ledPin = 13; // Pin 13 (also connected to built-in LED)
const int blinkDelay = 1000; // Delay in milliseconds (1000 ms = 1 second)

void setup() {
  // Initialize digital pin 13 as an output
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH); // Turn the LED ON (5V)
  delay(blinkDelay);          // Wait for 1 second

  digitalWrite(ledPin, LOW);  // Turn the LED OFF (0V)
  delay(blinkDelay);          // Wait for 1 second
}
